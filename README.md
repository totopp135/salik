# سالك (Salik) – Electronic Toll Collection

Server for the Salik graduation project: REST API, staff dashboard and the Flutter web app.

- `/app/` – the Salik app (drivers and staff)
- `/dashboard` – staff control center
- `/api/v1/...` – REST API

Run locally: `npm install`, create `.env` from `.env.example`, `npm start`.
On first start with an empty database the tables and demo data are created automatically.
